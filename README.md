# ⚡ ZYTI Trade

**Institutional Trading OS & Multi-Venue Terminal**

Plataforma de trading multiactivo de grado institucional diseñada para traders profesionales, brokers y empresas de fondeo (Prop Firms), con diseño moderno *Glassmorphism* y arquitectura modular.

---

### 🌟 Características Principales

- **📱 Experiencia Mobile-First:** Navegación inferior ergonómica, hoja deslizante a mitad de pantalla (`50dvh`) para no obstruir el análisis y botones flotantes de operación rápida con 1 toque.
- **💻 Terminal de Escritorio:** Riel de navegación lateral conmutable (izquierda/derecha) con apertura al hover, panel de órdenes avanzadas, libro de órdenes L2 y control de posiciones en tiempo real.
- **⏱️ Temporalidades e Indicadores:** Menú desplegable completo (desde segundos hasta anuales) con sistema de favoritos con estrellas (★).
- **🏢 Prop Firm Ready:** Pasarela preparada para auditoría de riesgo, control de drawdown y webhooks salientes en tiempo real.
- **🔒 Cero Secretos:** Arquitectura sanitizada y segura, lista para despliegue en Vercel con soporte SPA.

---

### 🚀 Instalación y Puesta en Marcha

```bash
# 1. Clonar el repositorio
git clone https://github.com/CSergio91/ZytiTrade.git
cd ZytiTrade

# 2. Instalar dependencias
npm install

# 3. Iniciar el entorno de desarrollo
npm run dev
```

La plataforma estará disponible en `http://localhost:5173`.
